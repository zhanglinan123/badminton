# HighlightCutter 🏸 羽毛球精彩集锦快剪工具

> 一款基于 Node.js + React 的羽毛球视频剪辑网页工具，支持键盘快捷键快速标记精彩片段，一键导出集锦视频。

---

## 📁 项目结构

```
HighlightCutter/
├── server.js            # 后端入口（Express + FFmpeg）
├── src/                 # 前端源码（React + TailwindCSS）
│   ├── App.tsx          # 主界面与核心逻辑
│   ├── main.tsx         # React 挂载入口
│   └── index.css        # 全局样式
├── dist/                # 前端构建产物（运行时由 Express 托管）
├── uploads/             # 上传视频临时目录（自动管理）
├── outputs/             # 输出视频目录（自动管理）
├── index.html           # Vite HTML 模板
├── vite.config.ts       # Vite 构建配置
├── tailwind.config.js   # TailwindCSS 配置
├── postcss.config.js    # PostCSS 配置
└── package.json         # 依赖与脚本
```

## 🚀 快速启动

### 前置条件

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | ≥ 18.0 | [下载地址](https://nodejs.org) |
| FFmpeg | 任意版本 | 必须加入系统 PATH，[下载地址](https://ffmpeg.org/download.html) |

验证 FFmpeg 是否可用：
```bash
ffmpeg -version
```

### 安装依赖

```bash
cd HighlightCutter
npm install
```

### 第一步：构建前端

> ⚠️ **每次修改 `src/` 目录后，需要重新构建才能在浏览器中生效。**

```bash
npm run build
```

### 第二步：启动服务

```bash
npm run start
```

启动成功后，终端输出：
```
Server running at http://localhost:3000
```

打开浏览器访问：**http://localhost:3000**

## 🎮 操作指南

### 第一步：上传视频

点击页面中央的上传区域，或直接拖拽视频文件到区域内。

- 支持格式：`MP4`、`MOV`、`AVI`、`MKV`、`WebM`
- 文件大小上限：`500 MB`

### 第二步：播放与定位

使用播放控件或点击进度条跳转到任意时间点：

| 操作 | 说明 |
|------|------|
| 点击播放器 / `空格键` | 播放 / 暂停 |
| ⏪ 倒退按钮 | 后退 5 秒 |
| ⏩ 快进按钮 | 前进 5 秒 |
| 点击进度条 | 跳转到任意时刻 |

### 第三步：标记精彩片段（键盘快捷键）

在视频播放到精彩镜头时，使用以下快捷键快速标记：

| 按键 | 功能 |
|------|------|
| **Q** | 标记当前时刻为**片段起点** |
| **W** | 标记当前时刻为**片段终点**，并将该段加入队列 |
| **E** | 撤销上一个已标记的片段 |

> 📝 按 **Q** 后，画面左上角会出现红色"录像中"提示，表示已记录起点。  
> 再按 **W** 确认终点，片段自动加入右侧列表。

### 第四步：管理片段队列

右侧面板显示所有已标记的片段：

- **点击时间戳**：跳转到该时刻
- **悬停 → 点击 🗑️**：删除该片段
- **点击"清空"**：清除全部片段
- 进度条上会以绿色高亮显示所有已标记区域

### 第五步：一键出片

确认片段无误后，点击底部绿色按钮：

```
一键出片（共 XX.X 秒）
```

系统将自动完成：
1. **逐段裁剪** 所有标记片段
2. **无缝拼接** 所有片段为一个完整视频
3. **自动下载** 最终集锦文件到本地

> ⏳ 处理时间取决于视频大小和片段数量，请耐心等待，勿关闭页面。

### 第六步：导出人工标注数据

如果要把人工标记用于调优回合识别，选择视频后点击 **导出标注 JSON**。系统会从视频元数据读取真实 FPS。

- 文件名格式：`原视频名.annotations.json`
- 时间单位：秒，保留 3 位小数
- 可以导出没有任何回合的空标注，作为负样本
- JSON 只保存标注，不复制原视频；请保留 JSON 与原视频的对应关系
- `fps` 由服务端探测视频流得到，不再使用固定默认值

示例：

```json
{
  "schema_version": 1,
  "task": "badminton_rally_segments",
  "source_video": "match_001.mp4",
  "fps": 60,
  "duration_seconds": 120.5,
  "annotations": [
    {
      "id": 1,
      "label": "rally",
      "start_seconds": 12.4,
      "end_seconds": 28.7,
      "duration_seconds": 16.3
    }
  ]
}
```

## 🔌 后端 API 说明

| 接口 | 方法 | 说明 |
|------|------|------|
| `POST /api/trim` | multipart | 裁剪单段视频 |
| `POST /api/merge` | multipart | 合并多个视频文件 |
| `POST /api/process-batch` | multipart | **一键出片核心接口**：接受原视频 + 标记数组，自动裁剪合并 |
| `GET /download/:filename` | - | 下载已处理的视频文件 |

### `/api/process-batch` 参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `video` | File | 原始视频文件 |
| `cuts` | JSON String | 标记数组，格式：`[{"start":"00:00:05","end":"00:00:12"},...]` |

## 🛠️ 开发模式

如需修改前端代码并实时预览，使用 Vite 开发服务器（需要两个终端）：

**终端 1 - 启动后端：**
```bash
npm run dev:server
```

**终端 2 - 启动前端开发服务器：**
```bash
npm run dev:ui
```

访问 **http://localhost:5173**（Vite 会自动代理 API 请求到 3000 端口）

> ⚠️ 注意：开发模式下需要在 `vite.config.ts` 中配置 proxy 才能正常代理 API：
> ```ts
> server: {
>   proxy: {
>     '/api': 'http://localhost:3000',
>     '/download': 'http://localhost:3000',
>   }
> }
> ```

## ❓ 常见问题

**Q: 点击"一键出片"没有反应或报错？**  
A: 检查后端服务是否在运行，并确认 `FFmpeg` 已正确安装并加入系统 PATH。

**Q: 视频上传后无法播放？**  
A: 请确认视频格式为 MP4/MOV，部分 AVI/MKV 编码格式浏览器可能不支持预览，但仍可正常裁剪。

**Q: 处理速度很慢？**  
A: 视频文件越大、标记片段越多，处理时间越长，属于正常情况。建议使用 H.264 编码的 MP4 文件以获得最快速度。

**Q: 修改代码后没有生效？**  
A: 前端修改需要执行 `npm run build` 重新构建后刷新浏览器；后端修改需要重启 `npm run start`。
